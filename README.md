# Каталог тем Video Downloader

Отсюда приложение скачивает темы оформления (Настройки → «Скачать темы…»)
в `%APPDATA%\com.nikol.videodl\themes\<id>\`.

## Как добавить тему

1. Соберите тему: папка с `theme.json` и картинками (png, webp, svg) или петлёй webm.
   Формат `theme.json` описан в README приложения, раздел «Своя тема».
2. Упакуйте её в архив `themes/<id>.zip`. `theme.json` должен лежать в корне архива
   или в одной вложенной папке. Размер темы до 100 МБ.
3. Добавьте запись в `index.json`:

```json
{
  "themes": [
    {
      "id": "ocean",
      "name": "Океан",
      "author": "я",
      "description": "Видеофон с волнами",
      "version": 1,
      "zip": "themes/ocean.zip"
    }
  ]
}
```

- `id`: имя папки темы на компьютере, только латиница, цифры, `-` и `_`.
- `zip`: путь к архиву от корня репозитория.
- `version`: чтобы выпустить обновление темы, увеличьте число. У тех, у кого тема уже стоит,
  появится кнопка «Обновить».

Приложение читает файлы из ветки `main`, поэтому изменения видны сразу после коммита.
